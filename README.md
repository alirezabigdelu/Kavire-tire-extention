# TireBot — افزونه‌ی کروم (کویر تایر)

نسخه‌ی افزونه‌ی کروم (Manifest V3) از یوزراسکریپت TireBot. کد اصلی بدون تغییر منطقی در `content.js` است.
پرداخت نهایی با خود شماست؛ ربات تا درگاه بانک پیش می‌رود.

## نصب (Chrome / Edge / Brave)
1. پوشه‌ی افزونه را از حالت زیپ خارج کنید.
2. به `chrome://extensions` بروید (در Edge: `edge://extensions`).
3. **Developer mode** را روشن کنید.
4. **Load unpacked** را بزنید و همین پوشه (که `manifest.json` داخلش است) را انتخاب کنید.
5. `kavirtire.ir/esale` را باز کنید و وارد حساب شوید. نوار TireBot بالای صفحه می‌آید.

## تنظیم ساعت شروع
روی آیکن افزونه کلیک کنید، ساعت شروع را بزنید و ذخیره کنید، سپس تب سایت را رفرش کنید.
(ساعت بر اساس منطقه‌ی زمانی دستگاه است؛ باید روی تهران باشد.)

بقیه‌ی تنظیمات (رینگ، درگاه، مدت، چرخش درگاه و...) مثل قبل از نوار داخل سایت انجام می‌شود.
برای تنظیمات پیشرفته (`CONFIG`) بالای `content.js` را ویرایش کنید و در `chrome://extensions` افزونه را Reload کنید.

## تفاوت با یوزراسکریپت
- نیازی به Tampermonkey نیست.
- ساعت شروع از پاپ‌آپ افزونه تنظیم می‌شود.
- مجوز لازم فقط `storage` و دسترسی به `kavirtire.ir` است. هیچ داده‌ای به بیرون ارسال نمی‌شود.
